# Dinesh Polavarapu

Personal portfolio of **Dinesh Polavarapu** — a mechanical engineering undergraduate at **IIT Tirupati**, independent systems builder, and founder of **Qraezev**.

Dinesh works at the intersection of robotics, artificial intelligence, and software systems. His interests include persistent cognitive memory for physical AI, autonomous systems, robotic control, and computational engineering. Through Qraezev, he is exploring ways for machines to retain and use experience to improve how they perform real-world tasks.

This site brings together Dinesh's background, projects, ventures, writing, and selected documents.

## Requirements

- Node.js
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal. The site is built with React, TypeScript, and Vite.
